## Quick reference
PATH is a saved list of folder addresses where PowerShell is allowed to look for commands.

code is the command name you type—the program you want PowerShell to find and run.
You type: code
        ↓
PowerShell checks each folder listed in PATH
        ↓
It finds: C:\Dev\Microsoft VS Code\bin\code.cmd
        ↓
PowerShell runs that file

A string is a sequence of characters stored and handled as text. A string literal is usually written inside matching quotation marks. ("")
